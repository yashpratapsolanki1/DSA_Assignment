# DSA Assignment – ITM University

A beginner-friendly Java collection for Data Structures and Algorithms, organized into five units.

## Units
| Unit | Topics |
|---|---|
| Unit 1 | Arrays, Strings, Sparse Matrices, Linked Lists |
| Unit 2 | Stacks, Queues, Polish Notation, Recursion |
| Unit 3 | Trees, Binary Trees, Binary Search Trees |
| Unit 4 | Graphs, BFS, DFS, Shortest Paths |
| Unit 5 | Sorting, Searching, File Structures, Hashing |

## Requirements
- JDK 8 or newer
- Any Java IDE or terminal

## Compile and run
```bash
javac ArrayBasics.java
java ArrayBasics
```

Each Java file is a standalone example. Confirm exact assignment requirements with your faculty and add your own test cases.
